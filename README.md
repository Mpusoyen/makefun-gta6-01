Palmera Heat is a top-down open-world crime game set in the city of Palmera at dusk, built as one static page. Explore a 7x6-block city on foot, steal and drive cars, run from a wanted system with real police pursuit, take missions from a contact by the park, and keep an eye on the live minimap. It has traffic with lane discipline, fleeing pedestrians, a respray bay that clears your heat, busted and wasted states, synthesized engine and siren audio, and progress that persists between visits.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
